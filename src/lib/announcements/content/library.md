This site has the functionality to import games from OGS, after which you can use the collaborative study tools built into analysis mode. Stored games from pros and strong players can be found on the [Library](/library), which is also where you can upload other games you're interested in.

When reviewing games in the library, the functionality is mostly identical to the post-game analysis functionality from ordinary games on this site. Anyone can investigate scenarios, place markers, or add notes. And if you're reviewing with others, everyone sees the same board at the same time.

Note that while you can see chats from the original games, if you send a chat it purposefully does **not** send it to OGS.
