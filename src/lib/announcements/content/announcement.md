Hi!

This is an announcement. In the past when I've put in new features I've been announcing them in the [chat room](/tv). But that means that only people who use the chat can see what the new features are, and that the list of functionality can get lost in the chat.

So now there are announcements. You can dismiss an announcement with the x in the top, or you can turn off announcements from showing up at all from settings.

I've also back-filled the announcements with other features you might not have seen! As always if you have any questions or concerns, you can reach out in [chat](/tv) or [on Github](https://github.com/Seth-Rothschild/libaduk/issues).
