One great way to learn about strategy games is to watch players who are better than you. We take the top game from [https://online-go.com/observe-games](https://online-go.com/observe-games) and display it in the bottom left corner of the landing page. When you click that game it takes you into our own page: [libaduk.com/tv](/tv).

The [tv](/tv) page of this site serves perhaps too many purposes. Not only does it have a game continuously playing, but it's also the only global "kibbitz" chat room for the entire site. Additionally, from within the chat, if you click the player names for a game it also acts as a link to see that game in the [Library](/library) for future study.

If you've got questions about the page or the site in general, the chat in the [tv](/tv) room is a great place to ask.
